# Site de Fã: Charlie Brown Jr.

Projeto desenvolvido durante o curso técnico em Segurança Cibernética (SATC). Na disciplina de desenvolvimento web, a proposta era escolher uma banda ou artista e criar um site completo sobre ela, seguindo os requisitos pedidos pela professora. Escolhi o Charlie Brown Jr. por ser uma banda de que sou muito fã.

🔗 **Site online:** [anajuliabirollo.github.io/site-charlie-brown-jr](https://anajuliabirollo.github.io/site-charlie-brown-jr/)

## O que tem no site

- **Página inicial** com carrossel de imagens e link para o Spotify da banda
- **Destaques** com informações rápidas (formação, primeiro e último álbum, legado)
- **Biografia** com origem do nome, estilo musical, influência cultural e legado
- **Integrantes clássicos** com foto e função de cada um
- **Discografia** com os 5 álbuns de maior sucesso e a lista de faixas
- **Galeria de fotos** com ampliação da imagem ao clicar
- **Notícias recentes** sobre a banda
- **Página de Fã-Clube** (contato.html)
- Menu de navegação entre as seções

## Tecnologias usadas

- HTML
- CSS
- JavaScript (carrossel do banner, galeria com ampliação e ano automático no rodapé)

## Como abrir

Baixe os arquivos e abra o `index.html` no navegador, ou acesse o link do site online acima.

## O que aprendi

- Estruturar um site com várias seções e páginas usando HTML
- Estilizar o layout com CSS
- Usar JavaScript para criar interações, como o carrossel e a galeria
- Organizar um projeto e publicá-lo no GitHub

## Aviso

Projeto escolar sem fins lucrativos. As imagens, nomes e conteúdos relacionados à banda pertencem aos seus respectivos autores e detentores de direitos.
